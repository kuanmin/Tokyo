
「しながわ宿場まつり」兩天的風格差很多。
* 第一天（土曜日）＝夜祭、花魁、江戶氛圍感
* 第二天（日曜日）＝大型傳統祭典、遊行、表演比較多
如果你是第一次去，我會覺得：
* 想拍照、感受「江戶風情」→ 第一天比較有趣
* 想看熱鬧的大型祭典活動 → 第二天比較有趣

第一天（土曜日）重點活動
2025 年的主要內容如下： 
1. おいらん道中（花魁遊行）
最有名、也是人氣最高的活動。
* 時間：約 16:00～19:30
* 華麗花魁穿著江戶時代服裝
* 用「外八文字」步法遊行
* 整條舊東海道超有江戶感
這個基本上就是大家專程去看的主秀。
尤其：
* 黃昏開始亮燈後氣氛很好
* 很適合攝影
* 有點像「大型時代劇現場」

2. 宿場ナイト（宿場 Night）
時間：約 17:30～20:30 
這個其實很有特色。
內容是：
* 商店街會變成「江戶夜晚」
* 有人扮成江戶町人
* 店家掛燈籠
* 可以邊吃邊喝邊逛
比較像：
「沉浸式江戶夜市」
不是單純看表演而已。

3. 各種攤販、舞台活動
白天開始就有：
* 小吃攤
* 地方物產
* 表演舞台
* 商店街活動
但核心還是：
「花魁＋夜晚氣氛」

第二天（日曜日）重點活動
1. しながわ宿場まつり行列（江戶風俗大遊行）
第二天最大主角。 
內容：
* 江戶時代扮裝隊伍
* 武士、町娘、飛腳等角色
* 大型 parade
整體比較：
「傳統祭典感」
不像第一天那麼夢幻，而是比較熱鬧正式。

2. 交通安全パレード
和遊行一起舉行。 
通常會有：
* 吹奏樂
* 小朋友隊伍
* 在地團體
偏地方祭典風格。

3. 火渡り荒行（火渡儀式）
13:00 左右，在品川寺。 
這個其實滿值得看。
山伏修行者會：
* 做護摩儀式
* 赤腳走火
很有日本宗教儀式感。

4. 人力車、表演、街頭活動
第二天通常會比第一天：
* 更多表演
* 更多 parade 類內容
* 更像「大型地方祭」

如果只能選一天，推薦：推薦「第一天（土曜日）」。
第一天下午到晚上：
* 花魁超有特色
* 夜晚氣氛很強
* 江戶感最完整
* 很有「東京少見」的感覺
而且：
品川宿本身就是以前花街文化很盛的地方
所以花魁道中放在這裡特別有味道。

兩天風格差異（最簡單版）
第一天（土）	第二天（日）
花魁、夜祭	大型傳統祭典
氣氛系	熱鬧系
適合拍照	適合看 parade
江戶浪漫感	在地祭典感
夜晚最精彩	白天最精彩
